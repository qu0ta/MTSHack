# МТС EnergyTool - ИИ-консультант

Веб-интерфейс консультанта EnergyTool. Для работы чата и заявок необходим запущенный Go API.

## Запуск

Нужен Node.js версии 20.19+ или 22.12+ и npm. Откройте терминал в папке `frontend` и выполните:

```bash
npm install
npm run dev
```

Vite покажет адрес в терминале, обычно это `http://localhost:5173/`. Чтобы остановить сервер, нажмите `Ctrl+C`.

В проекте используется npm и файл `package-lock.json`. Для повторной установки по зафиксированным версиям можно выполнить `npm ci`.

## Проверки

```bash
npm test
npm run lint
npm run build
```

## Подключение к API

В режиме разработки Vite перенаправляет запросы `/api`, `/health` и `/ready` на `http://localhost:8080`. Создание чата, история сообщений и сохранение заявки выполняются через Go API. Идентификатор текущего чата хранится в браузере.

Для запуска полного стека нужны настроенный AI-сервис и его ключи доступа. Настройки и инструкции находятся в корневом README и `ai/README.md`. Ключи моделей нельзя помещать во фронтенд или переменные `VITE_*`.

Сохранение заявки подтверждает запись в систему, но не подтверждает её отправку менеджеру по почте или в CRM.

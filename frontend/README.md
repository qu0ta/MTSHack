# МТС EnergyTool - ИИ-консультант

Локальный адаптивный React-прототип для демонстрации сценария консультации бизнес-клиента.

## Запуск

Нужен Node.js версии 20.19+ или 22.12+ и npm. Откройте терминал в папке `frontend` и выполните:

```bash
npm install
npm run dev
```

Vite покажет адрес в терминале, обычно это `http://localhost:5173/`. Чтобы остановить сервер, нажмите `Ctrl+C`.

В проекте используется npm и файл `package-lock.json`. Для повторной установки по зафиксированным версиям можно выполнить `npm ci`.

## Проверки

```bash
npm test
npm run lint
npm run build
```

## Архитектура интеграции

UI чата зависит от интерфейса `AssistantService` в `src/features/chat/api/assistantService.ts`. Сейчас подключён локальный mock-адаптер, чтобы интерфейс работал без бэкенда. При появлении API нужно добавить HTTP-реализацию того же интерфейса и заменить адаптер в `ChatWorkspace`.

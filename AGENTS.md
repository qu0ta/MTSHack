# Hack&Change 2026 — MTS EnergyTool

Ты работаешь над проектом хакатона Hack&Change 2026.

## Цель проекта

Разработать AI-консультанта для MTS EnergyTool.

Консультант должен:
- Отвечать на вопросы клиентов на основе базы знаний МТС.
- Выявлять потребности клиента.
- Рекомендовать подходящие продукты.
- Задавать уточняющие вопросы.
- Не выдумывать информацию.
- Собирать контакты клиента.
- Формировать заявку для менеджера.
- Поддерживать многошаговые диалоги.

## Архитектура

React Frontend
    ↓
Go Backend
    ↓
Python FastAPI
    ↓
AI Orchestrator
    ├── Dialog Manager
    ├── RAG Module
    ├── Prompt Builder
    └── LLM Client

PostgreSQL используется Go Backend для хранения истории и заявок.

## LLM

При локальной разработке допускаются доступные LLM.

При автоматической проверке используется модель Qwen3.8-27B через OpenAI-совместимый API организаторов.

Адрес и ключ передаются через:
- LLM_BASE_URL
- LLM_API_KEY
- LLM_MODEL

Код должен поддерживать переключение провайдера без изменения AI Orchestrator.

## Требования к коду

- Python 3.11+.
- FastAPI для HTTP API.
- Pydantic для схем данных.
- Асинхронные API-вызовы там, где это полезно.
- Модульная архитектура.
- Type hints.
- Разделение бизнес-логики и HTTP-слоя.
- Не хранить API-ключи в коде.
- Не изменять файлы других участников без согласования.
